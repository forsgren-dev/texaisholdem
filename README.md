
## Texas Hold'em against three AI powered opponents, a little experimental project by Erik Forsgren.

To try this out, place the API key to your LLM provider in a file named 'apikey.txt' and save it one folder above the TexAIsHoldem/ root. (Code uses .. to retrieve it.)

Set the model and API endpoint in Configuration/GameConfiguration.cs

Run the console program with 'dotnet run'

Win big!
